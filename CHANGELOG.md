# 📝 Changelog

All notable changes to **OpenMarketScanner** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-11-11
### Added
- Continuous integration GitHub Actions workflow with Python 3.10 and 3.11 test matrix.
- Institutional governance documentation: `CONTRIBUTING.md` and `SECURITY.md`.
- Structured version changelog.

## [1.0.0] - 2026-11-08
### Added
- Initial institutional release of 5,000+ US Equities Real-Time Market Scanner.
- Full 5,000+ US equities universe indexing with O(1) lookup speed.\n- Premarket gappers, Relative Volume (RVOL), and VWAP breakout algorithms.\n- Dynamic alert generation and multi-threaded market data processing.\n- Containerized Docker deployment configuration.
